Introduction to large language models

A language model scores token sequences, generates one token at a time, and can be adapted or prompted for many tasks. This guide emphasizes explanations, worked steps, and small calculations.

The big picture

1. From Transformer to language model

The previous lecture explained the Transformer as an architecture for relating positions in a sequence with attention. This lecture changes the question: what is the model trained to predict, and what can we do with those predictions? A language model assigns probabilities to sequences of tokens. A large language model is a language model with many learned parameters and broad training data.

Token

A unit in the model’s vocabulary: often a word, part of a word, punctuation, or another text fragment.

Context

The tokens already available to the model when it predicts the next token.

Completion

The continuation generated after a prompt, one token at a time.

Essay move: Define tokens and vocabulary, explain that a model gives probabilities to possible sequences, then connect the Transformer to computing those probabilities from context.
The core equation

2. Break a sequence into next-token decisions

Directly choosing an entire sentence is unwieldy. The autoregressive factorization uses the probability chain rule: predict the first token, then the second given the first, then the third given the first two, and so on. Multiplying those conditional probabilities gives the probability of that exact sequence. At position i\(i\), the model predicts xᵢ\(x_i\) from the earlier prefix x₁:ᵢ₋₁\(x_{1:i-1}\).

P(x₁, …, xₗ) = ∏ᵢ₌₁ᴸ P(xᵢ | x₁, …, xᵢ₋₁) For three tokens: P(a,b,c) = P(a) × P(b|a) × P(c|a,b)
\[P(x_{1:L})=\prod_{i=1}^{L}P(x_i\mid x_{1:i-1})\]\[P(a,b,c)=P(a)\,P(b\mid a)\,P(c\mid a,b)\]

This identity does not require independence between tokens. The condition after the vertical bar is precisely how earlier tokens can affect the next choice.

Work one small sequence

Suppose P(the) = 0.5, P(cat | the) = 0.4, and P(sat | the, cat) = 0.25. The exact three-token sequence has probability 0.5 × 0.4 × 0.25 = 0.05. Even reasonable long sentences tend to have tiny exact-sequence probabilities because many factors below one are multiplied.

From scores to text

3. Prompt, sample, repeat

Generation begins with a prompt. The model computes scores called logits for possible next tokens, converts them to probabilities, chooses a token, appends it to the context, and repeats. A prompt conditions the completion; it does not directly specify every word in the completion.

P(next token = i | context) = softmax(logitᵢ / T) T → 0: concentrate on the top logit T = 1: ordinary softmax T → ∞: approach uniform probabilities (for finite logits)
\[P(x_{t+1}=i\mid x_{1:t})=\left[\operatorname{softmax}\!\left(\frac{\boldsymbol z}{T}\right)\right]_i\]\[T\to0^+:\text{top token dominates},\quad T=1:\text{usual softmax},\quad T\to\infty:\text{approaches uniform}\]

Temperature T\(T\) changes the shape of the next-token distribution, not the underlying prompt. At very low temperature the highest-scoring token dominates; a higher temperature spreads probability more evenly. Sampling can still vary unless a deterministic choice is made.

Step-by-step answer: Given a prompt, compute next-token logits → adjust by temperature → softmax → choose or sample a token → append it → repeat until stopping. Low temperature does not make an answer factually correct; it mainly changes selection randomness.
What the model can see

4. Context size and the n-gram comparison

An n-gram model uses only a short recent history to predict the next token. This makes it cheap but can hide important earlier words. In “Rainbows usually appear opposite the ____,” a short history such as “opposite the” misses the clue “Rainbows.” Modern LLMs can use much longer contexts, but their context windows are still finite.

Short history

Fast and simple; may not include the evidence needed for a distant dependency.

Longer context

Can include more earlier tokens, but a longer window is not a guarantee of correct recall or reasoning.

Prompt design

Put the relevant instruction, examples, and evidence inside the usable context window.

Terminology check: In standard usage, an n-gram contains n tokens total, so a bigram predicts using one previous token and a trigram uses two. State the number of history tokens explicitly if a slide’s naming is ambiguous.
Same base model, different task

5. Adapt parameters or adapt the prompt

The lecture separates two ways to get useful task behavior. Supervised adaptation changes learned parameters using task data; prompting supplies instructions and examples in the context while leaving the model parameters fixed. A model may also have been adapted to follow instructions before you use it, so these are stages in a workflow, not mutually exclusive labels for an entire product.

ApproachWhat changes?Example exam explanation
Fine-tuningExisting model parameters are updated.Train on labeled input-output pairs for a target task.

Essay move: Answer “what changes?” first. For fine-tuning, weights change; for in-context examples, the input context changes. An example in a prompt does not by itself update the model’s weights.
Scoring predictions

6. Perplexity rewards likely test tokens

The product of many token probabilities gets very small as a sequence grows. Perplexity summarizes average surprise per token, using log probabilities. It is lower when a model assigns higher probability to the actual next tokens in the evaluation sequence.

PPL(x₁:ₗ) = exp[−(1/L) Σᵢ₌₁ᴸ ln P(xᵢ | x₁:ᵢ₋₁)] If two correct-token probabilities are 0.5 and 0.25: PPL = exp[−(ln 0.5 + ln 0.25)/2] = √8 ≈ 2.83
\[\operatorname{PPL}(x_{1:L})=\exp\!\left(-\frac{1}{L}\sum_{i=1}^{L}\log P(x_i\mid x_{1:i-1})\right)\]\[\text{If probabilities are }0.5,0.25:\quad \operatorname{PPL}=\sqrt{\frac{1}{0.5\cdot0.25}}=\sqrt{8}\approx2.83\]

A zero probability for a required test token makes its negative log probability, and therefore perplexity, infinite. Compare perplexities only under the same tokenization and evaluation setup. A low perplexity does not by itself establish truthfulness or usefulness.

Data split reminder: The lecture notes that evaluation data must not be part of training data. Otherwise the score can overstate generalization.

Exam rehearsal

8. Explain it, calculate it, compare it

Try each question before opening the answer. For calculations, write the formula, substitute values, and interpret the result.

What is an autoregressive language model?

It models a token sequence as a product of next-token conditional probabilities. At step i\(i\) it predicts xᵢ\(x_i\) from the prefix x₁:ᵢ₋₁\(x_{1:i-1}\). It can generate text by repeatedly selecting a next token and appending it to the prefix.

If P(a)=0.2, P(b|a)=0.5, and P(c|a,b)=0.4, find P(a,b,c).

By the chain rule, P(a,b,c)=0.2×0.5×0.4=0.04. This is the probability of that exact three-token sequence.

Explain how temperature affects generation.

The model divides logits by a positive temperature before softmax. Low temperature sharpens the distribution toward the top token; high temperature flattens it. At T=1 the usual softmax is used. T=0 is treated as a limiting or greedy choice rather than literal division by zero.

Contrast fine-tuning and few-shot prompting.

Fine-tuning trains existing parameters on task data. Few-shot prompting places a small number of demonstrations in the context and uses the same current parameters for the next prediction. A prompt example alone is not a gradient update.

Compute perplexity for two correct-token probabilities, both 0.25.

PPL=exp[−(ln 0.25+ln 0.25)/2]=1/0.25=4. Lower values mean the model assigned higher probabilities to the observed test tokens.

Why is accuracy on TruthfulQA different from low perplexity?

Perplexity measures probability assigned to held-out tokens. TruthfulQA examines whether answers to misconception-prone questions are truthful. Fluent or likely text can still be false.

What do GSM8K and MMLU test?

GSM8K uses multi-step grade-school math word problems. MMLU spans many subjects and tests broad knowledge and problem solving. Both are task evaluations, not direct measures of next-token perplexity.
