From pixels to a prediction

Imagine recognizing a handwritten digit. The input is a grid of pixel values. A CNN first looks for small patterns, such as edges or curves, at many locations. Later layers combine those responses into larger patterns. A final layer turns the resulting features into class scores.

1 · Convolution

Slide a small learned filter over local patches. Each position produces one number; together they form a feature map.

2 · Activation and reduction

Apply a nonlinearity such as ReLU. Some networks then pool or use a strided convolution to reduce the map's size.

3 · Prediction and learning

Combine the features into class scores. Compare the prediction with the label, then update the filter and later weights through backpropagation.

The next sections take that path one operation at a time. The little filter in the interactive example is fixed so you can follow the arithmetic; training is what would normally learn its values.

Connect to the last lecture

Why move beyond an MLP for images?

An MLP learns weights and biases, but a dense layer treats every image position as a separate input connection. A CNN still learns weights and biases; it places them in a small filter that scans the image. The same filter is reused at many positions, so the model can look for a pattern wherever it appears.

MLP viewpoint

Flatten the image, then connect inputs to neurons. Spatial neighbors are no longer explicit in the input layout.

CNN viewpoint

Keep height, width, and channels. A filter sees a local patch, then shares its weights across positions.

What stays familiar?

Predictions, loss, backpropagation, and optimization still apply. The architecture changes how features are computed.

What the architecture changes: Local connectivity lets each output use a small patch; weight sharing lets the same detector work across locations. Stacking layers combines those local detections into larger patterns.
The vocabulary behind the motion

What moves, and what changes its path?

A kernel or filter is a small set of learned weights. At one location it reads an equally sized patch, multiplies matching values, adds the products and a bias, and writes one number into a feature map. The same weights are reused at the next location. For a color image, the filter reaches through all input channels; each separate filter produces one output channel.

Stride

How many input cells the filter moves between positions. Stride 1 visits neighboring positions; stride 2 jumps two cells and usually makes a smaller output map.

Padding

Extra border cells, usually zeros. Valid convolution uses none; padding lets the filter cover the original edges and can preserve height and width.

Dilation

Spacing between the weights inside a filter. Rate 1 reads adjacent cells; rate 2 reads every other cell, so the same number of weights covers a wider area.

Activation

A function applied to each filter result. ReLU keeps positive values and changes negative ones to zero, allowing later layers to combine features nonlinearly.

Pooling

A fixed local summary, such as taking the maximum in a 2 × 2 window. It often reduces a feature map's size and has no learned filter weights.

In the walkthrough below, stride is 1, padding is 0, and dilation is 1. Later sections change those settings one at a time.

Core intuition

Local filters, shared weights, and receptive fields

A convolution filter is a small grid of trainable numbers. It slides across the input and produces a feature map: strong responses mark places where its learned pattern appears. A filter has depth equal to the number of input channels; multiple filters give multiple output channels.

Sparse interaction

A 3 × 3 filter reads only a nearby patch for one output location, rather than the entire image.

Parameter sharing

The same learned 3 × 3 weights are used at each location. This cuts parameter count and lets a pattern be found in different positions.

Receptive field

The part of the original input that can influence one output unit. Stacking layers or downsampling usually makes it larger.

Parameters = (kernel height × kernel width × input channels + 1 bias) × output channels
Example: (3 × 3 × 3 + 1) × 8 = 224
\[P=(k_h k_w C_{\mathrm{in}}+1)C_{\mathrm{out}}\]\[P=(3\cdot3\cdot3+1)\cdot8=224\]
Shape cue: With an input H × W × Cin and F filters, the output depth is F. Spatial height and width depend on kernel size, stride, padding, and dilation.
Change one setting at a time

Stride, padding, and dilation change what the filter sees

For each output cell, the filter needs a complete place to sit. With no padding, a 2 × 2 filter has three possible starting columns on a 4 × 4 input. A stride of 1 uses all three; a stride of 2 uses only the first and third. The same count applies to rows.

Stride changes the step

On a 4 × 4 input with a 2 × 2 filter and no padding, stride 1 gives a 3 × 3 map; stride 2 gives a 2 × 2 map. The filter weights do not change, only the locations visited.

Padding changes the border

A 3 × 3 filter on a 4 × 4 input would otherwise give 2 × 2 outputs. Add one zero border cell on every side and stride 1 gives 4 × 4, including responses centered near the original edge.

Dilation changes the spacing inside

A 2 × 2 filter at dilation 2 reads the four corners of a 3 × 3 region. It still has four weights, but its effective width is 3. On a 4 × 4 input with no padding and stride 1, the output is 2 × 2.

For one dimension, let \(n\) be input size, \(k\) filter size, \(p\) padding on each side, \(s\) stride, and \(d\) dilation. Count the valid starting positions with:

effective kernel = d(k − 1) + 1
output size = floor((n + 2p − effective kernel) / s) + 1
\[k_{\mathrm{eff}}=d(k-1)+1,\qquad n_{\mathrm{out}}=\left\lfloor\frac{n+2p-k_{\mathrm{eff}}}{s}\right\rfloor+1\]

Apply that formula separately to height and width. The number of filters sets output channels, not the spatial size. For the deck's dilated 2 × 2 example, the first filter position reads input letters \(a,c,i,k\), so its output is \(aw+cx+iy+kz\), shown on slide 32.

Downsampling

Pooling summarizes a neighborhood

Max pooling keeps the largest activation in each window. A 2 × 2 max-pool with stride 2 turns a 4 × 4 map into a 2 × 2 map. Pooling has no learned kernel weights; it performs a fixed summary of the values already produced by convolution and activation.

For [[1, 7], [4, 3]], 2 × 2 max-pooling returns 7. For a 4 × 4 map with non-overlapping 2 × 2 windows, compute four maxima.

Pooling also increases how much of the original image a later output can depend on. The lecture’s side view grows from a receptive field of 3 before pooling to 4 after a 2 × 2 pool.

What happens when an image moves? Convolution is translation equivariant: a shifted input can yield a correspondingly shifted feature map. Pooling can make a representation less sensitive to small shifts or size changes, but it does not guarantee perfect invariance. Ordinary CNNs also have no automatic rotation invariance.
When the output needs more pixels

Upsampling and transposed convolution

Classification can reduce an image to a few scores. Dense prediction, such as a segmentation mask, needs an output value at many image positions. After feature maps have been reduced, the network must enlarge them again.

Upsampling

Enlarge a map with a fixed interpolation rule. The lecture's nearest-neighbor example repeats each value into a 2 × 2 block: [[a, b], [c, d]] becomes a 4 × 4 grid with four copies of each value. Bilinear interpolation blends nearby values instead.

Transposed convolution

A learned operation that can increase spatial size while combining features. It is often used on the way to dense outputs. Despite the name, it is not generally the inverse of an earlier convolution.

How the weights change

Training learns the filter and the classifier

In the walkthrough, the numbers in the filter and the final class scores were fixed for clarity. During training, they are parameters the model adjusts from labeled examples.

1

Run the image forward through convolution, activation, any pooling, and the classifier to obtain scores.

2

Compare those scores with the correct label using a loss. A wrong or uncertain prediction produces a learning signal.

3

Backpropagation sends that signal through the classifier and earlier layers. Because one filter is reused at many positions, its gradient combines information from every place it was used; an optimizer then changes its weights.

Follow the path backward: max pooling sends gradient through the value that won each window, while ReLU blocks it where the pre-activation was negative. The same MLP training loop still applies, but the forward operations now respect image structure.
Deeper models

How do deep CNNs keep training?

Repeated convolution layers learn increasingly broad features, but deep networks can suffer vanishing or exploding gradients and unstable training. The lecture introduces residual connections and batch normalization as two tools used in deeper CNNs.

Residual connection

Instead of learning the entire output from scratch, a block can learn a change F(x) and add the input back: y = F(x) + x (often followed by an activation).

Batch normalization

During training it uses batch statistics to normalize activations, then applies learned γ and β. It can make deep optimization more stable.

Do not overclaim: these methods help training, but neither guarantees that every deep model will train well. Batch normalization also behaves differently at training and inference because inference uses accumulated statistics.
Check your understanding

Explain, calculate, compare

Try each question before opening its answer. Use the worked example above when you need to trace a filter again.

1. Why is a CNN usually more parameter efficient than a dense MLP on an image?

A CNN uses small local filters rather than a separate learned weight from every pixel to every output unit. It shares each filter's weights across positions, so the same pattern detector works in many places. The parameter count for a convolution layer is (k²Cin + 1)Cout, independent of spatial image width and height for fixed channel counts.

2. A 7 × 7 input receives a 3 × 3 filter, padding 1, stride 2. What is the spatial output?

Apply floor((n + 2p − k)/s) + 1 to each dimension: floor((7 + 2 − 3)/2) + 1 = floor(3) + 1 = 4. The spatial output is 4 × 4. If there are F filters, its full shape is 4 × 4 × F.

3. A layer has 16 input channels and 32 filters of size 3 × 3, each with one bias. How many learned parameters?

Each filter has 3 × 3 × 16 = 144 weights plus 1 bias. With 32 filters: (144 + 1) × 32 = 4,640 parameters.

4. Distinguish stride, padding, and max pooling.

Stride is the step between filter positions during convolution. Padding adds border values, often zeros, which affects edge coverage and spatial size. Max pooling is a fixed operation that keeps the maximum from each local window to downsample a feature map. They can all affect spatial resolution, but they do it in different ways.

5. What changes when a 2 × 2 filter uses dilation 2 on a 4 × 4 input?

The filter still has four weights, but they read the corners of a 3 × 3 region. With no padding and stride 1, the effective kernel size is 3, so each spatial output dimension is floor((4 − 3)/1) + 1 = 2. Dilation spaces out the weights; stride changes how far the whole filter moves between outputs.

6. Why might a CNN upsample instead of pool?

Pooling reduces spatial size and is useful when a compact feature summary suffices. A segmentation mask needs a prediction at many image locations, so a model can enlarge feature maps with fixed interpolation or a learned transposed convolution.

7. Explain equivariance, scale robustness, and rotation in a CNN.

Shared convolution filters make feature responses shift as the input shifts, which is translation equivariance. Pooling and later layers may make predictions more robust to modest position or scale changes, but exact invariance is not guaranteed. Ordinary CNNs are not inherently rotation invariant; rotated data augmentation can help them learn such robustness.

8. Why use a skip connection in a deep CNN?

A residual block computes a transformation and adds an identity path from an earlier activation. That path can carry information and gradients across layers, helping mitigate optimization difficulties such as vanishing gradients.
