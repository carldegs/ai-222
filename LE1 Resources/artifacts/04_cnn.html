Why move beyond an MLP for images?

An MLP learns weights and biases, but a dense layer treats every image position as a separate input connection. A CNN still learns weights and biases; it places them in a small filter that scans the image. The same filter is reused at many positions, so the model can look for a pattern wherever it appears.

MLP viewpoint

Flatten the image, then connect inputs to neurons. Spatial neighbors are no longer explicit in the input layout.

CNN viewpoint

Keep height, width, and channels. A filter sees a local patch, then shares its weights across positions.

What stays familiar?

Predictions, loss, backpropagation, and optimization still apply. The architecture changes how features are computed.

Essay answer pattern: A CNN learns local features with small filters, shares those parameters across image locations, and builds increasingly abstract feature maps over layers. Explain both local connectivity and weight sharing; “CNNs are good for images” alone is too vague.
Core intuition

Local filters, shared weights, and receptive fields

A convolution filter is a small grid of trainable numbers. It slides across the input and produces a feature map: strong responses mark places where its learned pattern appears. A filter has depth equal to the number of input channels; multiple filters give multiple output channels.

Sparse interaction

A 3 × 3 filter reads only a nearby patch for one output location, rather than the entire image.

Parameter sharing

The same learned 3 × 3 weights are used at each location. This cuts parameter count and lets a pattern be found in different positions.

Receptive field

The part of the original input that can influence one output unit. Stacking layers or downsampling usually makes it larger.

Parameters = (kernel height × kernel width × input channels + 1 bias) × output channels
Example: (3 × 3 × 3 + 1) × 8 = 224
\[P=(k_h k_w C_{\mathrm{in}}+1)C_{\mathrm{out}}\]\[P=(3\cdot3\cdot3+1)\cdot8=224\]
Shape cue: With an input H × W × Cin and F filters, the output depth is F. Spatial height and width depend on kernel size, stride, padding, and dilation.

At each position, multiply matching entries and add them. In deep-learning libraries this operation is usually cross-correlation, though the lecture calls it convolution.

Light computation

Predict output size before multiplying

For an ordinary square filter, calculate each spatial dimension separately. Let n be input width or height, k kernel size, p padding on each side, and s stride.

output size = floor((n + 2p − k) / s) + 1 For dilation d > 1, replace k with effective kernel size d(k − 1) + 1.

Downsampling

Pooling summarizes a neighborhood

Max pooling keeps the largest activation in each window. A 2 × 2 max-pool with stride 2 turns a 4 × 4 map into a 2 × 2 map. Pooling has no learned kernel weights; it performs a fixed summary of the values already produced by convolution and activation.

For [[1, 7], [4, 3]], 2 × 2 max-pooling returns 7. For a 4 × 4 map with non-overlapping 2 × 2 windows, compute four maxima.
Nuance for an essay: convolution is translation equivariant: a shifted input can yield a correspondingly shifted feature map. Pooling can make a representation less sensitive to small shifts or size changes, but it does not guarantee perfect invariance to every translation or scale. Ordinary CNNs also have no automatic rotation invariance.
Deeper models

How do deep CNNs keep training?

Repeated convolution layers learn increasingly broad features, but deep networks can suffer vanishing or exploding gradients and unstable training. The lecture introduces residual connections and batch normalization as two tools used in deeper CNNs.

Residual connection

Instead of learning the entire output from scratch, a block can learn a change F(x) and add the input back: y = F(x) + x (often followed by an activation).

Batch normalization

During training it uses batch statistics to normalize activations, then applies learned γ and β. It can make deep optimization more stable.

Do not overclaim: these methods help training, but neither guarantees that every deep model will train well. Batch normalization also behaves differently at training and inference because inference uses accumulated statistics.
Exam rehearsal

Explain, calculate, compare

Try answering each prompt before opening the response. A strong essay answer gives the mechanism and its consequence.

1. Why is a CNN usually more parameter efficient than a dense MLP on an image?

A CNN uses small local filters rather than a separate learned weight from every pixel to every output unit. It shares each filter's weights across positions, so the same pattern detector works in many places. The parameter count for a convolution layer is (k²Cin + 1)Cout, independent of spatial image width and height for fixed channel counts.

2. A 7 × 7 input receives a 3 × 3 filter, padding 1, stride 2. What is the spatial output?

Apply floor((n + 2p − k)/s) + 1 to each dimension: floor((7 + 2 − 3)/2) + 1 = floor(3) + 1 = 4. The spatial output is 4 × 4. If there are F filters, its full shape is 4 × 4 × F.

3. A layer has 16 input channels and 32 filters of size 3 × 3, each with one bias. How many learned parameters?

Each filter has 3 × 3 × 16 = 144 weights plus 1 bias. With 32 filters: (144 + 1) × 32 = 4,640 parameters.

4. Distinguish stride, padding, and max pooling.

Stride is the step between filter positions during convolution. Padding adds border values, often zeros, which affects edge coverage and spatial size. Max pooling is a fixed operation that keeps the maximum from each local window to downsample a feature map. They can all affect spatial resolution, but they do it in different ways.

5. Explain equivariance, scale robustness, and rotation in a CNN.

Shared convolution filters make feature responses shift as the input shifts, which is translation equivariance. Pooling and later layers may make predictions more robust to modest position or scale changes, but exact invariance is not guaranteed. Ordinary CNNs are not inherently rotation invariant; rotated data augmentation can help them learn such robustness.

6. Why use a skip connection in a deep CNN?

A residual block computes a transformation and adds an identity path from an earlier activation. That path can carry information and gradients across layers, helping mitigate optimization difficulties such as vanishing gradients.
