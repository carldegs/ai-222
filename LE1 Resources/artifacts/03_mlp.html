From a DataLoader batch to an MLP

Last lecture ended with a DataLoader yielding (xbatch, ybatch). This lecture supplies the model that takes each input x, computes a prediction ŷ = f(x; θ), and compares it with the target y.

\[ (x_{\mathrm{batch}},y_{\mathrm{batch}})\ \xrightarrow{\mathrm{DataLoader}}\ \hat y=f(x;\theta),\qquad L=L(y,\hat y) \]

Here θ means the learnable weights and biases. A loss tells us how wrong the predictions are; optimization changes θ to reduce that loss on training data. Evaluation still uses held-out data, as in the earlier lectures.

Essay opening: “An MLP is a feed-forward function approximator built by stacking learned linear transformations and activation functions. It maps input features to an output, then learns its weights and biases by minimizing a loss.”
Core mechanism

1. Trace one layer, then stack layers

For one layer, multiply the incoming values by weights, add a bias, then apply an activation. The activation makes the composition capable of modelling nonlinear relationships. Without nonlinear activations between layers, several linear layers collapse into one linear transformation.

\[ z^{(i)}=W^{(i)}a^{(i-1)}+b^{(i)},\qquad a^{(i)}=\sigma_i\!\left(z^{(i)}\right) \]

Weights W

Control how strongly each incoming feature contributes to each new unit.

Biases b

Shift a unit's pre-activation value, even when its inputs are zero.

Activation σ

Transforms the weighted sum. Hidden-layer nonlinearity is the key reason stacked layers can express richer functions.

One-neuron walkthrough: If x = (2, −1), weights are (0.5, 3), and bias is 1, then z = (0.5)(2) + (3)(−1) + 1 = −1. With ReLU, output is max(0, −1) = 0. Show the weighted sum before applying the activation.
Light computation

2. Flattening, dimensions, and parameters

An ordinary MLP expects a feature vector per example. A 28 × 28 × 1 image can be flattened into 784 numbers. If a layer has din inputs and dout units, its weight matrix has shape dout × din and its bias vector has dout values.

\[ \#\text{parameters}=d_{\mathrm{in}}d_{\mathrm{out}}+d_{\mathrm{out}}=(d_{\mathrm{in}}+1)d_{\mathrm{out}} \]

Worked example: A 4-feature input goes through 3 hidden units and then 2 outputs. First layer: 4×3 + 3 = 15 parameters. Output layer: 3×2 + 2 = 8. Total: 23 learnable parameters. Activation functions add no learnable parameters in this example.

Try your own two-layer count

Use positive whole numbers. The count includes both weight matrices and both bias vectors.

(4 × 3 + 3) + (3 × 2 + 2) = 23 parameters.

Shape check: With batch size B, the input is B × din and the output is B × dout. B changes how many examples are processed together; it does not multiply the number of model parameters.
Choose the right output

3. Activation functions

Hidden activations add nonlinearity. The output activation depends on what the prediction must mean. ReLU keeps positive inputs and maps negative inputs to zero; sigmoid maps one number into (0, 1); softmax turns a vector of class scores into class probabilities that sum to one.

\[ \operatorname{ReLU}(z)=\max(0,z),\qquad \operatorname{softmax}(z)_i=\frac{e^{z_i}}{\sum_{k=1}^{C}e^{z_k}} \]
ActivationTypical roleWhat to say in an exam
ReLUHidden layersSimple nonlinearity: zero below 0, identity above 0.
SigmoidBinary probability outputOne score becomes a value between 0 and 1.
SoftmaxSingle-label, multi-class outputClass scores become a distribution that sums to 1.
LinearUnconstrained numeric outputNo output squashing, useful when predicting a real number.
Quick calculation: ReLU(−2, 0, 3) = (0, 0, 3). For softmax, first exponentiate each class score, then divide each exponential by their sum. A larger score gets a larger probability, but softmax considers the whole vector.
How learning happens

4. Loss, optimization, and the training recipe

The MLP's forward pass gives a prediction. A loss function compares that prediction with the true label and returns a number to minimize. Training repeatedly uses batches, computes loss, obtains gradients, and updates the weights and biases. The lecture names stochastic gradient descent (SGD), Adam, and AdamW as optimizers.

MSE / MAE

Common for numeric prediction. MSE squares errors, emphasizing large mistakes; MAE uses absolute differences.

Cross-entropy

Common for classification. It penalizes low probability assigned to the true class; binary and multi-class forms differ.

  1. Initialize parameters. Set weights and biases to starting values.
  2. Load a batch. The DataLoader supplies input tensors and labels.
  3. Forward pass. Apply each layer in order to compute predictions.
  4. Compute loss. Compare predictions against the labels.
  5. Update parameters. Backpropagation computes gradients; the optimizer takes an update step. Repeat over batches and epochs.
  6. Evaluate. Use validation for design choices and the test set for final held-out performance.
Light computation: With true values (1, 3) and predictions (2, 1), squared errors are 1 and 4. Mean squared error is (1 + 4) / 2 = 2.5; mean absolute error is (1 + 2) / 2 = 1.5. State the averaging step when the question asks for a mean.
Design choices

5. Prepare the inputs; tune the right things

The slides distinguish parameters, which learning updates, from hyperparameters, which the practitioner chooses or tunes. Input scaling can help training behave well. Labels must also be encoded in a form compatible with the task and chosen loss.

Learned during trainingChosen or tuned around training
Weights and biasesDepth, width, activation choice, learning rate, batch size, epochs, optimizer

Examples of input preparation include rescaling values to [0, 1] or standardizing features to roughly zero mean and unit variance. For classification, the expected target representation depends on the loss implementation: some interfaces take class indices, others take one-hot or probability vectors. Always check the loss function's contract.

Essay connection: A high training score but weak test score may reflect overfitting, dataset problems, or mismatched preprocessing. Explain the data and model decisions together instead of blaming only the MLP architecture.
Self-test

6. Practice the likely question styles

Try each answer before opening it. In an essay, define the term, state its role, then connect it to the full training pipeline.

Essay: What is an MLP, and why does it need nonlinear activations?

An MLP is a feed-forward network of layers. Each layer applies a learned weighted sum and bias, followed by an activation. Hidden nonlinearities let the composition represent nonlinear relationships; stacking only linear transformations would still be equivalent to one linear transformation. The output layer converts the learned representation into predictions suited to the task.

Step-by-step: Describe one training iteration from DataLoader to parameter update.
  1. Receive an input batch and target batch.
  2. Run the inputs through the MLP to obtain predictions.
  3. Calculate a task-appropriate loss against the targets.
  4. Compute gradients by backpropagation.
  5. Use an optimizer to update weights and biases.

Across iterations, validate choices on validation data and reserve test data for final evaluation.

Compute: A 5 → 4 → 3 MLP has how many learnable parameters?

First layer: 5×4 + 4 = 24. Second layer: 4×3 + 3 = 15. Total: 39. The activation functions add none here.

Compare: When would you use sigmoid, softmax, or a linear output?

Use sigmoid for a binary probability, softmax for one class among several mutually exclusive classes, and a linear output for an unconstrained numeric prediction. The loss must match the task and the output convention.

Compute: What does ReLU do to (−3, 2, 0), and what does softmax guarantee?

ReLU gives (0, 2, 0). Softmax maps a vector of class scores to nonnegative probabilities whose sum is one.

Explain: Parameters versus hyperparameters?

Weights and biases are learned from the training data. Hyperparameters such as layer widths, learning rate, batch size, epochs, and optimizer are selected or tuned around that learning process, usually with validation evidence.
