01 · Overview and supervised learning

Learning and evaluation

AI ⊃ ML ⊃ deep learning. ML fits behavior from examples; deep learning learns representations and predictions through multiple neural layers. Large datasets, parallel GPU computation, and training methods made older neural-network ideas practical at scale.

E, T, P: experience supplies examples, the task defines the desired behavior, and a performance measure evaluates improvement. For digit recognition: labeled images, predict a digit, and accuracy on unseen images.

What is the model learning?

Given an input, the model uses its adjustable parameters to make a prediction. Training compares that prediction with the correct target across the training examples.

\[\hat y=f(x,\theta)\qquad R_{\mathrm{emp}}(\theta)=\frac1N\sum_{n=1}^{N}\ell\bigl(y_n,f(x_n,\theta)\bigr)\]

\(x\): input; \(y\): target; \(\hat y\): prediction; \(\theta\): weights and biases; \(N\): number of training examples; \(\ell\): loss for one example. The sum adds the losses and division by \(N\) gives their average. Training aims to reduce that average.

Example: TP=18, FP=6, FN=2 gives precision \(18/24=0.75\) and recall \(18/20=0.90\). If the correct class receives probability 0.75, CE = \(-\operatorname{ln}(0.75) \approx 0.288\).

Prediction versus causation: observing \(p(y|x)\) is different from intervening on x, \(p(y|do(x))\); a counterfactual asks what would have happened under another action.

  1. Set the data and parameters. \(x=2\), target \(y=4\), \(w=1\), \(b=0\), learning rate \(\eta=0.1\). Use \(L=(\hat y-y)^2\) for this single example (no ½ factor).
  2. Forward: \(\hat y=1\times 2+0=2\). Error \(e=2-4=-2\). Loss \(L=(-2)^2=4\).
  3. Backward: \(\frac{\partial L}{\partial \hat y}=2e=-4\); \(\frac{\partial \hat y}{\partial w}=x=2\); \(\frac{\partial \hat y}{\partial b}=1\). Thus \(\frac{\partial L}{\partial w}=-8\) and \(\frac{\partial L}{\partial b}=-4\).
  4. Update together using the old gradients: \(w′=1-0.1(-8)=1.8\); \(b′=0-0.1(-4)=0.4\).
  5. Check the new model: \(\hat y′=1.8\times 2+0.4=4\); \(L′=0\) on this one example. Other examples may still have error. In a batch, average the examples’ losses and gradients.

How does one dense layer compute its outputs?

Each destination neuron takes a weighted sum of all input features and adds its own bias. Its activation function transforms that sum.

\[a=Wx+b,\qquad h=\phi(a),\qquad \#\text{parameters}=mn+m\]

\(x\in\mathbb R^n\) contains \(n\) input features; \(W\in\mathbb R^{m\times n}\) contains weights for \(m\) neurons; \(b,a,h\in\mathbb R^m\). \(\phi\) is the activation, such as ReLU. Each row of \(W\) supplies one neuron’s incoming edge weights. Count \(mn\) edges and \(m\) biases.

FunctionDefinitionTypical role
ReLU\(\operatorname{max}(0,z)\)Nonlinear hidden layers.
Sigmoid\(\frac{1}{1+e^{-z}}\)One binary probability; also gates.
Tanh / softplusTanh lies in (−1,1); softplus = \(\operatorname{ln}(1+\operatorname{exp}(z))\).Centered bounded activation / smooth positive activation.
Softmax\(p_i=\frac{\exp(z_i)}{\sum_j\exp(z_j)}\)Competing classes; probabilities sum to 1.

Clear accumulated gradients→Forward pass→Compute loss→Backpropagate→Optimizer update

Backpropagation computes derivatives through the network. The optimizer uses them to change weights and biases.

How does a gradient change a parameter?

After the forward pass and loss calculation, backpropagation tells us how changing each parameter would change the loss. Gradient descent takes a small step in the direction that reduces it locally.

\[\theta_{\mathrm{new}}=\theta_{\mathrm{old}}-\eta\nabla_\theta L\]

\(L\): training loss; \(\nabla_\theta L\): derivatives with respect to the parameters; \(\eta\): learning rate. A negative derivative increases that parameter under this update. The “One complete learning step” example in Learning and evaluation calculates both derivatives and then applies this rule.

Count and update: a \(4\to 3\to 2\) MLP has \((4\times 3+3)+(3\times 2+2)=23\) parameters. For \(\hat y=wx\), \(x=2\), \(y=4\), \(w=1\), \(L=(\hat y-y)^2\): \(\hat y=2\), \(L=4\), \(\frac{\partial L}{\partial w}=2(wx-y)x=-8\). With \(\eta=0.1\), w becomes 1.8.

Practical details: scale features appropriately, initialize weights, and match target format to loss. In PyTorch, CrossEntropyLoss receives raw logits and usually integer class targets; BCEWithLogitsLoss receives logits and combines sigmoid with BCE internally. Avoid applying the output activation twice.

04 · Convolutional neural networks

Local filters and spatial structure

A filter slides across a grid, multiplies corresponding entries, and sums them. Each filter spans all input channels and produces one output channel. The same weights are reused across spatial locations; local connections reduce parameters relative to a dense image layer.

Input H×W×Cᵢₙ→F shared filters→Feature maps→ReLU / pooling→Prediction

A receptive field is the region of the original input that can influence an output. Stacking layers grows it.

How large is a convolution’s output?

Use this before drawing the output grid. First find the kernel’s effective footprint, including dilation, then count the valid starting positions along each axis.

\[K_{\mathrm{eff}}=D(K-1)+1,\qquad O=\left\lfloor\frac{I+2P-K_{\mathrm{eff}}}{S}\right\rfloor+1\]

\(I\): input length along one axis; \(K\): kernel size; \(D\): dilation; \(P\): padding on each side; \(S\): stride; \(O\): output length. Apply once to height and once to width. For \(F\) filters spanning \(C_{\mathrm{in}}\) channels, the parameter count is \(F(C_{\mathrm{in}}K_hK_w+1)\), with one bias per filter. The grid comparisons below show what each setting changes.

OperationWhat changesCommon confusion
StrideSpacing between filter starting positions.Larger stride usually reduces spatial output size.

Upsampling / transposed convolutionInterpolation enlarges a grid; transposed convolution learns a spatial expansion.Transposed convolution is not a guaranteed inverse of convolution.
Example: \(I=32\), \(K=3\), \(P=1\), \(S=2\), \(D=1\) gives \(O=\operatorname{floor}(31/2)+1=16\). Eight filters over 3 input channels have \(8(3\times 3\times 3+1)=224\) parameters and produce \(16\times 16\times 8\). A \(2\times 2\) max pool with stride 2 takes one maximum per region and produces \(8\times 8\times 8\).

Equivariance: shifting an input tends to shift a convolution’s response, subject to borders and sampling. Pooling can reduce sensitivity to small shifts; arbitrary rotation invariance is not built in.

Training through depth

Vanishing gradients give earlier layers tiny corrections; exploding gradients produce excessive updates and unstable loss. ResNet adds a shortcut: \(y=x+F(x)\), giving the gradient a direct identity path alongside the learned path. If dimensions differ, use a projection. BatchNorm normalizes activations with training-batch statistics, then learns scale γ and shift β; inference uses running statistics.

What does BatchNorm do to an activation?

During training, BatchNorm recenters and rescales activations using batch statistics, then applies a learned scale and shift. This controls the scale of signals flowing through a network.

\[\hat x=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\varepsilon}},\qquad y=\gamma\hat x+\beta\]

\(x\): activation; \(\mu_B\), \(\sigma_B^2\): training-batch mean and variance; \(\varepsilon\): small positive constant; \(\gamma\), \(\beta\): learned scale and shift. For CNNs, statistics are usually per channel across batch and spatial positions. Inference uses running statistics. Residual shortcuts instead add a separate path; they perform a different job.

05 · Recurrent neural networks

State across time

An RNN uses the current input and previous hidden state to form new memory. Unrolling draws the same cell at successive times; the parameters are shared, not separate learned networks. The hidden state is a compressed, lossy summary rather than a copy of all earlier inputs.

How does an RNN carry information to the next time step?

Compute the new hidden state from the current input and previous state. Then use that state to produce output scores. Repeat with the same weights for the next input.

\[\begin{aligned}h_t&=\tanh(b+Wh_{t-1}+Ux_t)\\o_t&=c+Vh_t,\qquad \hat y_t=\operatorname{softmax}(o_t)\end{aligned}\]

\(x_t\): input at time \(t\); \(h_{t-1}\), \(h_t\): old and new hidden states; \(U\): input weights; \(W\): recurrent weights; \(V\): output weights; \(b,c\): biases; \(o_t\): logits. For input width \(d\), hidden width \(H\), and \(K\) classes: \(U:H\times d\), \(W:H\times H\), \(V:K\times H\). The example below computes two steps, carrying the first hidden value into the second.

x₁ + h₀ → h₁→x₂ + h₁ → h₂→x₃ + h₂ → h₃

The U input transform and W state transform are reused at every step; V maps a selected state to output scores.

Teacher forcing: training feeds the correct previous target token; inference feeds the previously generated token. Inference errors can compound. Teacher forcing does not remove a separate sequential hidden-state dependency. Backpropagation through time sends gradients through the unrolled chain.

Repeated transformations can shrink or grow gradients: factors of 0.5 repeated four times give 0.0625; factors of 2 give 16. Gradient clipping limits explosions. LSTM and GRU gates help retain useful memory; they still use sequential recurrence.

LSTM memory and gates

How does an LSTM decide what to keep, write, and expose?

An LSTM carries a cell-memory vector and a hidden-state vector. Three sigmoid gates control the retained memory, admitted candidate content, and exposed output. Follow the equations from top to bottom.

\[\begin{aligned}z_t&=[h_{t-1};x_t]\\f_t&=\sigma(W_fz_t+b_f),&i_t&=\sigma(W_iz_t+b_i)\\C_t&=\tanh(W_Cz_t+b_C)\\s_t&=f_t\odot s_{t-1}+i_t\odot C_t\\q_t&=\sigma(W_qz_t+b_q),&h_t&=q_t\odot\tanh(s_t)\end{aligned}\]

Lecture notation: \(s_t\) is cell memory, \(C_t\) is candidate content, and \(q_t\) is the output gate. \(f_t\) keeps old memory; \(i_t\) admits new content. \(z_t\) concatenates the old hidden state and current input. Each \(W\) and \(b\) is a learned transform and bias. \(\sigma\) is sigmoid; \(\odot\) multiplies matching coordinates. The worked example below calculates the gates before updating either state.

One memory coordinate: old memory 0.8, \(f=0.9\), \(i=0.2\), candidate \(C=-0.5\) gives s=\(0.9\times 0.8+0.2\times (-0.5)=0.62\). With \(q=0.5\), h=\(0.5 \operatorname{tanh}(0.62)\approx 0.276\). Both memory and hidden state travel forward.

06 · Transformer

Attention and the Transformer block

Self-attention lets a token combine information directly from permitted positions. The input matrix X has n token rows and d feature columns. Learned projections create queries, keys, and values: queries and keys determine weights; values supply the information mixed by those weights.

How does attention combine information from tokens?

For each query token, compare its query with every permitted key, convert those scores into weights, then take a weighted sum of the value vectors.

\[\begin{aligned}Q&=XW_Q,\quad K=XW_K,\quad V=XW_V\\A&=\operatorname{softmax}_{\mathrm{row}}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)\\\text{context}&=AV\end{aligned}\]

\(X\): one row per input token; \(W_Q,W_K,W_V\): learned projections; \(Q,K\): queries and keys; \(V\): values; \(d_k\): query/key width; \(M\): mask, with \(0\) for allowed entries and \(-\infty\) for blocked entries. \(A\) holds attention weights. With \(n\) tokens, \(A\) is \(n\times n\); each row sums to \(1\). The two-token example below explicitly computes the score matrix, mask, weights, and mixture.

Project Q, K, V→Dot-product scores→Scale and mask→Row-wise softmax→Weighted value sum

Scaling by √dₖ moderates score growth with vector width. Each allowed row of attention weights is nonnegative and sums to 1.

One query: \(q=\begin{bmatrix}1&0\end{bmatrix}\), \(k_{1}=\begin{bmatrix}1&0\end{bmatrix}\), \(k_{2}=\begin{bmatrix}0&1\end{bmatrix}\), values 10 and 2. Dot products \(\begin{bmatrix}1&0\end{bmatrix}\) become \(\begin{bmatrix}0.707&0\end{bmatrix}\) after scaling by √2. Softmax ≈\(\begin{bmatrix}0.670&0.330\end{bmatrix}\), so the blended value is \(0.670\times 10+0.330\times 2\approx 7.36\).

07 · Large language models

Token probabilities and generation

A language model assigns probabilities to token sequences. Tokens can be words, word pieces, punctuation, or other units. Autoregressive modeling conditions each token on the earlier prefix; it does not assume tokens are independent.

How does a language model score a sequence?

Predict each token from its preceding prefix. Multiply these conditional probabilities to score the whole sequence; use negative log probabilities to calculate a training loss.

\[P(x_1,\ldots,x_L)=\prod_{i=1}^{L}P(x_i\mid x_1,\ldots,x_{i-1}),\qquad \mathrm{PPL}=\exp\left(\frac1L\sum_{i=1}^{L}-\ln p_i\right)\]

\(L\): number of scored tokens; \(x_i\): token at position \(i\); \(p_i\): probability assigned to the actual token given its prefix. One token’s loss is \(-\ln p_i\). Perplexity exponentiates their average. Natural logs are used. The first token is conditioned on an empty prefix or a beginning-of-sequence marker. Compare perplexity only under the same tokenization and evaluation setup.

Prompt tokens→Next-token logits→softmax(logits / T)→Choose a token→Append and repeat

Temperature \(T>0\) controls concentration: lower T sharpens, higher T flattens, \(T=1\) gives ordinary softmax. \(T\to 0\) is a limit, not literal division by zero.

Probability: \(P(a)=0.2\), \(P(b|a)=0.5\), \(P(c|a,b)=0.4\) gives \(P(a,b,c)=0.04\). Perplexity: observed-token probabilities 0.5 and 0.25 give \(\mathrm{PPL}=(0.5\times0.25)^{-1/2}=\sqrt{8}\approx2.83\). Assigning zero probability to an observed token makes the penalty infinite.

08 · LLM data and model

Text to representations

A corpus supplies training examples; a tokenizer defines the discrete units; embeddings turn IDs into vectors; the sequence model contextualizes those vectors. A large web corpus can still underrepresent languages or populations. Filtering improves some qualities while changing coverage; deduplication reduces repeated training material and helps prevent evaluation contamination.

Text→Token pieces→Integer IDs→Embedding lookup→Contextual model→Prediction

IDs identify vocabulary entries; their numerical distances do not encode meaning. A token’s initial vector can be fixed while its later representation changes with context.

09 · Agents

Decisions and checked actions

A workflow follows developer-defined steps or branches. An agent chooses actions from intermediate observations to pursue a goal. An embodied agent also senses and acts in a physical environment. Perception interprets raw signals; planning chooses a step; acting executes it; feedback checks the outcome.

Observation→Reasoning / planning→Permitted action→Tool result or changed environment→New observation

Memory informs decisions. The model proposes a tool call; the surrounding application validates and executes it, returns the result, and controls stopping.

How much context is left for retrieved memory?

An agent must fit its instructions, task, retrieved material, and tool results into the model’s context budget while leaving room for an answer.

\[\text{instructions}+\text{task}+\text{memory}+\text{tool results}+\text{output reserve}\leq\text{context limit}\]

These terms are token counts, not learned model parameters. With a simplified input budget of \(12{,}000\) tokens, subtracting \(1{,}000\) for instructions, \(2{,}000\) for the task, and \(3{,}500\) for tool results leaves \(5{,}500\) for memory. A real run must also reserve output and overhead.

Bring the concepts together

Explain and calculate

State the mechanism, trace the data or state through it, and check the assumptions behind the result.

Why can a model have high training accuracy but poor real performance?

It may overfit, learn biased coverage, encounter distribution shift, or benefit from leakage in the evaluation. Check independent held-out data and the deployment population.

Which quantities change during training, prompting, and retrieval?

Training changes parameters θ. Prompting changes the current input. Retrieval adds selected external evidence to that input. Prompting and retrieval do not themselves train weights.

Count a 784→128→10 MLP and compare a \(3\times 3\) RGB filter bank with 16 filters.

MLP: \((784\times 128+128)+(128\times 10+10)=101,770\) parameters. Convolution: \(16(3\times 3\times 3+1)=448\). These counts concern the stated layers, not two complete equivalent models.

Find output size for I=7, \(K=3\), \(P=1\), \(S=2\), \(D=1\), then \(D=2\).

\(D=1\) gives K_eff=3 and O=floor(\((7+2-3)/2\))+1=4. \(D=2\) gives K_eff=5 and O=floor(\((7+2-5)/2\))+1=3.

Trace hₜ=\(0.5h_{t-1}+x_{t}\) from \(h_{0}=0\) and inputs [1,1,0].

h₁=1; h₂=1.5; h₃=0.75. This arithmetic toy uses identity activation, rather than the standard tanh cell.

Which LSTM vector is stored memory, and what do its three gates do?

In the lecture notation, s is stored memory; C is candidate content; f retains old memory, i admits new content, and q exposes tanh(s) as h. Hidden state and stored memory are separate vectors.

With X shaped \(5\times 8\) and W_Q shaped \(8\times 4\), what are Q and the score matrix?

\(Q is 5\times 4\). With five compatible keys, \(QK^\top\) is \(5\times 5\), giving 25 scores. V need not have the same feature width as Q and K.

Mix values 4 and 10 with attention weights 0.25 and 0.75.

\(0.25\times 4+0.75\times 10=8.5\). These are already normalized weights; do not apply softmax again.

Why is a causal mask needed even with teacher forcing?

Training has future target tokens available, but a position must not read the answer it is supposed to predict. The mask blocks future positions; teacher forcing supplies the correct prefix.

Can BatchNorm, LayerNorm, and residual connections be used interchangeably?

They solve different problems. BatchNorm uses batch statistics; LayerNorm normalizes a token’s features. A residual shortcut adds an identity or projected path to help information and gradients flow.

If each correct token has probability 0.25, what is perplexity? Does it measure truth?

Average loss is −ln(0.25); exponentiating gives PPL=4. It measures surprise on observed tokens, not factual truth or successful task completion.
