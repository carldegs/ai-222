Start with an ordered input

1. Why does order matter?

“Dog bites person” and “Person bites dog” contain the same words but mean different things. An RNN reads a sequence one item at a time. It carries a hidden state—a changing vector of numbers that summarizes what it has read so far. When the next item arrives, the model combines that item with its previous state.

A CNN reuses a filter across image locations. An RNN reuses the same state-update weights across time steps. The weights stay fixed during one pass; the hidden state changes with the input.

CNN question

“What local pattern is at this spatial position?” A shared kernel scans an image.

RNN question

“Given what I have seen so far, how should I interpret this next item?” Shared weights update the state over time.

Typical sequence

Words in a sentence, audio frames, sensor readings, or even image rows treated in order.

Keep the distinction: The same learned rule is applied at each time step, but the state it produces depends on the previous state and the current input.
Core mechanism

2. Unroll the loop and update the hidden state

At each step, an RNN does one thing: combine the next input with its current memory to make an updated memory. That memory is the hidden state. First understand what moves from one step to the next; then read the equations as instructions for doing that update.

What are the input, cell, and hidden state?

Input xₜ: the next item

The subscript t is the position in the sequence. For “Dog bites person,” x₁ represents “Dog,” x₂ represents “bites,” and x₃ represents “person.” Each word must first be encoded as a vector of numbers; the cell does not calculate with the word itself.

Hidden state hₜ: memory after this item

A fixed-length vector of numbers that can carry useful information about inputs x₁ through xₜ. “Hidden” means it is an internal representation, rather than the target label. Its coordinates are learned features, not a literal list of the words read.

Cell: the update rule

A small computation that takes two vectors—xₜ and hₜ₋₁—and produces hₜ. The same cell, with the same learned weights, runs again for the next item.

What does “unroll the loop” mean?

A loop arrow means “send the state back into this cell when the next input arrives.” Unrolling draws those successive uses side by side, so you can see which state belongs to which time step. The boxes represent the same computation at different times, with shared weights.

Start: h₀ = an initial state (often all zeros) Step 1: (h₀, x₁) → same cell → h₁ memory after “Dog” Step 2: (h₁, x₂) → same cell → h₂ memory after “Dog bites” Step 3: (h₂, x₃) → same cell → h₃ memory after “Dog bites person”

Read hₜ₋₁ as “memory before reading item t” and hₜ as “memory after reading it.” Step 2 must wait for h₁ because h₁ is one of its inputs. Earlier words affect a later state through this chain; the cell is not handed every earlier word again.

Two different kinds of change: Reading the sequence changes h₁, h₂, h₃. Learning during training changes the weights. During one forward pass through a sequence, the weights are reused unchanged. “Update the hidden state” means compute a new memory vector.

How does one cell compute the new memory?

The lecture uses a basic RNN with tanh activation. Its two state-update equations are:

aₜ = b + W hₜ₋₁ + U xₜ hₜ = tanh(aₜ)
\[\begin{aligned} a_t &= b + W h_{t-1} + U x_t \\ h_t &= \tanh(a_t) \end{aligned}\]
  1. Transform the current input: Uxₜ. Multiply the input vector by the learned matrix U to produce a contribution with the same size as the hidden state.
  2. Transform the old memory: Whₜ₋₁. Multiply the previous hidden state by the learned matrix W. This lets the cell mix and reweight the information it carried forward.
  3. Add both contributions and the bias b. The resulting vector aₜ is the intermediate value before activation. A bias is a learned offset, added even when an input value is zero.
  4. Apply tanh to each coordinate. This nonlinear function maps each value into the range −1 to 1. The result is hₜ, which becomes the old memory at the next step.

The matrix letters are names, not extra states: U and W are learned parameters; xₜ is supplied by the sequence; hₜ is computed. The same U, W, and b are used at every position. The hidden state has the same number of coordinates throughout the sequence, so it must compress earlier information and can lose details.

A worked update with a two-number hidden state

Use small, illustrative weights so we can do the arithmetic. Let xₜ = [1, 0, 1], hₜ₋₁ = [0.2, −0.4], and b = [0, 0]. Take U = [[0.5, 0, 0.5], [0, 1, 0]] and W = [[0.5, 0], [0, 0.5]]. Vectors are treated as columns in the matrix products.

Current input contribution: U xₜ = [0.5×1 + 0×0 + 0.5×1, 0×1 + 1×0 + 0×1] = [1, 0] Old memory contribution: W hₜ₋₁ = [0.5×0.2 + 0×(−0.4), 0×0.2 + 0.5×(−0.4)] = [0.1, −0.2] Combine, then activate: aₜ = [0, 0] + [0.1, −0.2] + [1, 0] = [1.1, −0.2] hₜ = [tanh(1.1), tanh(−0.2)] ≈ [0.8005, −0.1974]

That new two-number vector is passed to the next cell together with xₜ₊₁. It contains contributions from both the current input and the old state. You cannot assign a word or a human meaning to either coordinate just from these numbers.

How does memory become a prediction?

The hidden state is an internal representation. When the task needs a class prediction at step t, a separate output calculation reads that representation:

oₜ = c + V hₜ raw class scores (logits) ŷₜ = softmax(oₜ) predicted class probabilities
\[\begin{aligned} o_t &= c + V h_t \\ \hat y_t &= \operatorname{softmax}(o_t) \end{aligned}\]

V maps the hidden vector to one score per class; c is an output bias. Softmax converts these scores into probabilities that sum to 1. For example, two scores [2, 1] give probabilities of approximately [0.73, 0.27]. This output calculation does not replace hₜ: the next recurrent step still receives hₜ as its memory. A task may use an output at every step or only after the final input.

Where does training enter this picture?

If the correct class at step t is yₜ, its loss is Lₜ = −log P(yₜ | x₁, …, xₜ). Giving the correct class a low probability creates a larger loss. Training propagates that error backward through the unrolled computation and adjusts the shared U, W, V, b, and c. For predictions at every step, the losses across steps are combined. This is separate from computing new hidden states during a forward pass.

Training versus use

4. Teacher forcing changes what feeds the next step

During training, a decoder may be given the correct previous output as input to the next step. That is teacher forcing. At test time, the correct future outputs are unavailable, so the decoder must feed back its own prediction. One mistake can then influence later predictions.

Training

Previous ground-truth token → next prediction. Known targets can be prepared in advance.

Inference

Previous predicted token → next prediction. Generating the next token must wait for the current prediction.

One important limit: Teacher forcing removes the wait for a predicted output during training in the lecture’s feedback design. If hidden states themselves depend on hₜ₋₁, that state chain still has to be computed in order.
More context

5. Bidirectional RNNs and encoder–decoders

A one-way RNN sees the past as it moves forward. A bidirectional RNN has a second pass from the other direction, so a position can use both earlier and later context. This works when the full input sequence is available; it cannot use future input that has not arrived yet in a live stream.

For sequence-to-sequence translation, an encoder reads the source, and its final summary is passed as a context vector C to a decoder. This is an intuitive pattern, but asking one fixed vector to hold a long source sequence creates a bottleneck.

A deep RNN stacks transformations: one recurrent layer can pass its output to another, while an MLP can transform an input, hidden state, or output. A skip connection gives information a shorter route past a layer. Both change the network depth; neither changes the basic idea of carrying state across time.

Compare the mechanisms: Bidirectionality changes which input context each position can use. Encoder–decoder changes how one input sequence is converted into another output sequence.
Why the next architecture matters

6. Long sequences are hard

Information and training signals must travel through many recurrent steps. Repeated multiplication by weights can make a signal shrink toward zero or grow too large. That is why a basic RNN struggles with long-term dependencies.

Toy scalar recurrence: hₜ = w hₜ₋₁ ⇒ hₜ = wᵗ h₀ If w = 0.5: after 4 steps the factor is 0.0625 (shrinks). If w = 2: after 4 steps the factor is 16 (grows).
\[h_t = w h_{t-1} \quad\Longrightarrow\quad h_t = w^t h_0\]\[0.5^4=0.0625\quad\text{(shrinks)},\qquad 2^4=16\quad\text{(grows)}\]

In a full network, the gradient calculation is more involved, but this toy power illustrates the decay/explosion intuition on slide 30. The lecture lists skip connections, leaky units, gradient clipping, LSTMs, and GRUs as responses. An LSTM uses gates to control what information is forgotten, added, and exposed.

Gradient clipping caps an excessively large update during training; it addresses exploding gradients but does not restore a signal that has already vanished. A leaky unit blends some previous state with new information, giving the old state a route forward. LSTM cells use a forget gate to retain or discard old memory, an input gate to admit new information, and an output gate to expose part of memory as the hidden state. A GRU is another gated recurrent cell with a simpler gate arrangement. Gates are learned controls, not manually chosen switches.

What is an LSTM, and why use it?

LSTM means Long Short-Term Memory. It is an RNN cell with a separate memory vector and three learned gates that control what to keep, write, and expose. It still processes a sequence one step at a time and shares its weights across steps.

A basic RNN repeatedly transforms its entire hidden state with tanh\(\tanh\). An LSTM gives memory an additional, additive route through time: retain some old memory, then add selected new content. If the forget gate is near 1 and the input gate is near 0, memory can pass forward almost unchanged. This often makes long-term dependencies easier to learn, although it does not guarantee perfect recall or remove sequential computation.

Step-by-Step LSTM Walk Through

One step receives the current input xₜ\(x_t\), the previous hidden state hₜ₋₁\(h_{t-1}\), and the previous cell memory sₜ₋₁\(s_{t-1}\). First join the input and hidden vectors: zₜ = [hₜ₋₁; xₜ]\(z_t = [h_{t-1}; x_t]\), where the semicolon means concatenation.

  1. Decide what old memory to keep. Compute the forget gate fₜ = σ(W_f zₜ + b_f)\(f_t = \sigma(W_f z_t + b_f)\). The first ×\(\times\) circle produces fₜ ⊙ sₜ₋₁\(f_t \odot s_{t-1}\). A value near 1 retains that coordinate; near 0 suppresses it.
  2. Propose new content and decide how much to write. Compute the input gate iₜ = σ(W_i zₜ + b_i)\(i_t = \sigma(W_i z_t + b_i)\) and candidate Cₜ = tanh(W_C zₜ + b_C)\(C_t = \tanh(W_C z_t + b_C)\). The middle ×\(\times\) circle produces iₜ ⊙ Cₜ\(i_t \odot C_t\). The gate controls quantity; the candidate supplies signed content.
  3. Update the stored memory. The + circle adds retained memory and selected new content: sₜ = fₜ ⊙ sₜ₋₁ + iₜ ⊙ Cₜ\(s_t = f_t \odot s_{t-1} + i_t \odot C_t\). Pass sₜ\(s_t\) along the upper path to the next step.
  4. Choose what to expose as the hidden state. Compute qₜ = σ(W_q zₜ + b_q)\(q_t = \sigma(W_q z_t + b_q)\). The right-hand tanh\(\tanh\) box transforms sₜ\(s_t\); the final ×\(\times\) circle gives hₜ = qₜ ⊙ tanh(sₜ)\(h_t = q_t \odot \tanh(s_t)\). Pass hₜ\(h_t\) to the next step too. A separate output layer can read hₜ\(h_t\) to predict a class or word.
zₜ = [hₜ₋₁; xₜ] fₜ = sigmoid(W_f zₜ + b_f) keep old memory iₜ = sigmoid(W_i zₜ + b_i) admit new content Cₜ = tanh(W_C zₜ + b_C) candidate content sₜ = fₜ ⊙ sₜ₋₁ + iₜ ⊙ Cₜ updated cell memory qₜ = sigmoid(W_q zₜ + b_q) expose memory hₜ = qₜ ⊙ tanh(sₜ) new hidden state
\[\begin{aligned}z_t &= [h_{t-1};x_t] \\ f_t &= \sigma(W_f z_t+b_f) \\ i_t &= \sigma(W_i z_t+b_i) \\ C_t &= \tanh(W_C z_t+b_C) \\ s_t &= f_t\odot s_{t-1}+i_t\odot C_t \\ q_t &= \sigma(W_q z_t+b_q) \\ h_t &= q_t\odot\tanh(s_t)\end{aligned}\]

Symbols: Each W\(W\) is a learned matrix and each b\(b\) a learned bias; the suffix identifies its branch. ⊙\(\odot\) means elementwise multiplication, not a matrix product. All gates are vectors, so different memory coordinates can be treated differently. Stored memory sₜ\(s_t\) is not restricted to −1 through 1; its tanh\(\tanh\)-transformed version is.

One-coordinate example: Suppose old memory is 0.8, fₜ = 0.9\(f_t = 0.9\), iₜ = 0.2\(i_t = 0.2\), and candidate Cₜ = −0.5\(C_t = -0.5\). New memory is sₜ = 0.9 × 0.8 + 0.2 × (−0.5) = 0.62\(s_t = 0.9 \times 0.8 + 0.2 \times (-0.5) = 0.62\). If qₜ = 0.5\(q_t = 0.5\), then hₜ = 0.5 × tanh(0.62) ≈ 0.276\(h_t = 0.5 \times \tanh(0.62) \approx 0.276\). Both 0.62 and 0.276 travel forward, in separate state vectors.

Explain why an RNN is suited to sequential data. Compare it with a CNN.

A sequence has an order that can change the meaning of an item. An RNN updates hₜ\(h_t\) from hₜ₋₁\(h_{t-1}\) and xₜ\(x_t\), so its current representation includes earlier context. The same recurrent parameters are reused at every step. A CNN also reuses weights, but its shared kernels scan spatial locations to detect local image patterns. The basic RNN’s state chain requires ordered computation.

Walk through one RNN step and name U\(U\), W\(W\), V\(V\), b\(b\), and c\(c\).

Compute aₜ = b + W hₜ₋₁ + U xₜ\(a_t = b + W h_{t-1} + U x_t\), then hₜ = tanh(aₜ)\(h_t = \tanh(a_t)\). For a class output, compute oₜ = c + Vhₜ\(o_t = c + Vh_t\) and ŷₜ = softmax(oₜ)\(\hat y_t = \operatorname{softmax}(o_t)\). U\(U\) maps input to hidden state, W\(W\) maps previous state to new state, V\(V\) maps hidden state to output, and b\(b\) and c\(c\) are biases. All are shared across steps.

With h₀ = 0\(h_0 = 0\), hₜ = 0.5hₜ₋₁ + xₜ\(h_t = 0.5h_{t-1} + x_t\), and x = [1, 1, 0]\(x = [1, 1, 0]\), find h₁\(h_1\), h₂\(h_2\), h₃\(h_3\).

h₁ = 0.5(0)+1 = 1\(h_1 = 0.5(0)+1 = 1\); h₂ = 0.5(1)+1 = 1.5\(h_2 = 0.5(1)+1 = 1.5\); h₃ = 0.5(1.5)+0 = 0.75\(h_3 = 0.5(1.5)+0 = 0.75\). This is an arithmetic toy using identity activation, not the lecture’s tanh\(\tanh\) cell.

If input, hidden, and class sizes are 3, 2, and 4, what are the shapes of U\(U\), W\(W\), V\(V\)?

U\(U\) is 2×3\(2\times3\) so Uxₜ\(Ux_t\) has size 2. W\(W\) is 2×2\(2\times2\) so Whₜ₋₁\(Wh_{t-1}\) has size 2. V\(V\) is 4×2\(4\times2\) so Vhₜ\(Vh_t\) has size 4 logits.

Contrast teacher forcing at training time with inference.

Training can feed the known correct previous output into the next decoder step. At inference, the correct next outputs are unknown, so the model feeds back its previous prediction. Prediction errors can compound. This feedback distinction does not remove a separate hidden-state recurrence when one is present.

Which RNN pattern fits sentiment classification, image captioning, and translation?

Sentiment classification: sequence-to-vector, because many words yield one label. Image captioning: vector-to-sequence, because one image yields words. Translation: encoder–decoder sequence-to-sequence, because source and target sentences can differ in length.

Why can a basic RNN fail on long-term dependencies? Give two remedies.

Repeated transformations across time can make information or gradients shrink or explode, so distant evidence becomes difficult to learn from. The lecture lists gradient clipping, skip connections, leaky units, LSTM, and GRU. Clipping addresses exploding gradients; gated units help preserve or control useful memory.
