Why replace recurrence with attention?

An RNN carries a hidden state from one time step to the next. A Transformer instead lets each token compare itself with other tokens through attention. This can connect distant positions directly and compute many positions in parallel. Position must then be supplied explicitly.

RNN

Context flows through repeated state updates: earlier → later. The path between distant tokens can be long.

Transformer

Each attention layer computes weighted connections among tokens. An encoder can view the whole input sequence at once.

Key tradeoff

Full self-attention forms token-to-token scores, so its score matrix grows as the square of sequence length.

Essay answer pattern: State how an RNN passes context sequentially, how self-attention connects positions directly, and why the Transformer needs position information. “It remembers better” is too vague without the mechanism.
Start with the shape

Tokens become vectors

A sentence is a sequence of n\(n\) token embeddings. Each embedding has d\(d\) numbers. Stack the row vectors into an input matrix X ∈ Rⁿˣᵈ\(X\in\mathbb{R}^{n\times d}\). In the lecture’s toy picture, “cat opened its” has three tokens, each represented by a four-number vector.

Shape check: three tokens with four features each means the input matrix is 3 × 4. The same word can acquire a different contextual output when surrounding words change.
Core computation

Query, key, value: choose what matters

Learned projections turn each input vector into a query, a key, and a value. A query asks what information this position needs; keys are compared with that query; values provide the information to blend. These are three learned views of the same input, not three separate input sequences.

Q = XW_Q, K = XW_K, V = XW_V Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V
\[Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V\]\[\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\mathsf{T}}{\sqrt{d_k}}\right)V\]

The softmax is applied across keys for each query row. Its weights are nonnegative and add to 1, so each output row is a weighted sum of value rows. Dividing by √dₖ\(\sqrt{d_k}\) keeps dot-product scores from becoming overly large as vector width grows.

Work one query row

Suppose one query is q = [1, 0]\(q=[1,0]\), two keys are k₁ = [1, 0], k₂ = [0, 1]\(k_1=[1,0],\ k_2=[0,1]\), and their scalar values are 10 and 2.

1

Dot products: 1 and 0.

2

Scale by √2\(\sqrt 2\): scores become about 0.707 and 0.

3

Softmax: weights are about 0.670 and 0.330.

4

Blend values: 0.670(10) + 0.330(2) ≈ 7.36\(0.670(10)+0.330(2)\approx 7.36\).

Exam shortcut: If softmax weights are already given, go directly to the weighted sum. If scores are given, scale and normalize before multiplying by values.

Reveal the pipeline one step at a time

Project the input X three ways to obtain Q, K, and V. Each token has a row in each matrix.
Strong short answer: Attention compares a query with every permitted key, turns scores into weights, and takes a weighted sum of the corresponding values. Name the row-wise softmax and scale if asked for the full mechanism.
More than one comparison pattern

Why multiple attention heads?

Each head has its own learned query, key, and value projections. One head can emphasize one relationship while another emphasizes a different one. The head outputs are concatenated and passed through an output projection. Multiple heads do not mean repeatedly applying softmax to one shared score matrix.

headᵢ = Attention(XWᵢᴽ, XWᵢᴷ, XWᵢⱽ) MultiHead(X) = concat(head₁, …, headₕ) Wᴼ
\[\mathrm{head}_i=\operatorname{Attention}(XW_i^Q,XW_i^K,XW_i^V)\]\[\operatorname{MultiHead}(X)=\operatorname{concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^O\]
Light shape example: With model width 8 and two heads of width 4, each head returns n × 4\(n\times4\). Concatenation returns n × 8\(n\times8\) before the final projection.
Order matters

How does a Transformer know token order?

Without position information, self-attention sees token vectors but has no built-in sequence order. The lecture adds a positional vector to each input embedding before the encoder. The slide also mentions learned positions and rotary positional embedding as other approaches.

input at position i = token embedding xᵢ + positional vector pᵢ Both vectors must have the same width.
\[\widehat{x}_i=x_i+p_i\qquad (x_i,p_i\in\mathbb{R}^{d})\]
Essay answer pattern: Self-attention relates token content, and positional information supplies sequence order. State where the position information enters. You usually do not need to memorize every sine/cosine term to explain its purpose.
Whole architecture

Encoder, decoder, and the future mask

An encoder block combines multi-head self-attention with a feed-forward network applied at each position. The lecture adds layer normalization and residual connections around these sublayers. An encoder–decoder model then uses decoder self-attention, encoder–decoder attention, and a final projection plus softmax to predict outputs.

PartWhat it may attend toWhy it exists
Encoder self-attentionInput tokens, typically in both directionsBuild context-aware input representations
Masked decoder self-attentionCurrent and earlier output positionsPrevent future-token leakage during training and generation
Encoder–decoder attentionEncoder outputsLet generated output consult the input
Masking detail: Disallowed future positions receive an effectively −∞\(-\infty\) score before softmax, so their attention weight becomes zero. The mask controls visibility; it does not erase token embeddings.
Essay answer pattern: Trace a source token through embedding plus position, encoder self-attention, and feed-forward layers. Then trace a target prefix through masked decoder self-attention, cross-attention to encoder outputs, and the final vocabulary prediction.
Exam rehearsal

Explain, trace, calculate

Try each prompt before opening the answer. Give the operation and its purpose in short essays.

1. Compare an RNN with a Transformer for long sequences.

An RNN passes information step by step through a hidden state. A Transformer’s attention can connect distant positions directly and process sequence positions in parallel. Full self-attention also requires a token-pair score matrix, which grows quadratically with sequence length; position information must be supplied.

2. If the input is 5 × 8 and the query projection is 8 × 4, what shape are the queries? How many attention scores arise with five keys?

The query matrix is 5 × 4: one four-feature query per token. Comparing five queries with five keys gives a 5 × 5 score matrix, or 25 scores.

3. Two values are 4 and 10, with attention weights 0.25 and 0.75. What is the output?

Take the weighted sum: 0.25(4) + 0.75(10) = 1 + 7.5 = 8.5. The weights sum to 1.

4. Explain query, key, and value without calling them separate sentences.

They are learned projections of the input vectors. A query is compared with keys to calculate attention weights; those weights blend the values into a contextual output.

5. Why scale dot-product scores?

Larger query/key dimensions can lead to larger dot products. Dividing by √dₖ\(\sqrt{d_k}\) moderates their magnitude so softmax is less likely to become extremely peaked, which helps learning.

6. What do multiple heads contribute?

Separate learned projections let different heads form different attention patterns. Their outputs are concatenated and linearly projected into the block’s output representation.

7. Why does a decoder need a causal mask?

When predicting the next token, a position must not access future output tokens. The mask makes those future attention weights zero, so training matches the information available during generation.

8. Distinguish encoder self-attention from encoder–decoder attention.

Encoder self-attention compares positions within the input. Encoder–decoder attention lets a decoder position query representations from the encoder, bringing source context into output generation.
