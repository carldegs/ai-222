Start with a concrete problem

Suppose you want a computer to recognize handwritten digits. You give it many images, each paired with the correct digit. It predicts a digit, compares that prediction with the answer, and changes its internal numbers to improve. After training, you give it images it has never seen. That last step tells you whether it learned a useful pattern rather than memorized the examples.

The whole path: labeled examples \((\mathbf{x},y)\) → a model predicts \(\hat y\) → loss measures the mistake → parameters \(\theta\) change → unseen examples test generalization.

Overview deck

1. AI, machine learning, and deep learning

Artificial intelligence is the broad ambition: machines that show capabilities such as reasoning, planning, problem solving, abstraction, and learning. Machine learning is one route to AI: rather than writing every decision rule, we fit a model from examples. Deep learning is machine learning using multi-layer neural networks that learn useful features and decisions together.

ApproachWhat is provided by people?What is learned?
Rule-based AIRules, templates, conditionsTypically nothing; the behavior is specified.
Classical MLFeatures are usually hand-designed.A decision rule/classifier over those features.
Deep learningArchitecture, objective, dataUseful representations/features and the decision mapping.
The key distinction: Deep learning learns useful features from examples along with the final prediction rule. Classical machine learning often starts from features designed by people.

2. Why deep learning became practical

The underlying ideas are older than the current AI boom: perceptrons, CNNs, and backpropagation existed decades earlier. The modern change was the combination of large datasets, powerful parallel GPU computation, and successful training practices. AlexNet’s 2012 ImageNet result is a landmark example, not proof that one model “invented” deep learning.

Why GPUs help: Many tensor calculations can run in parallel, making training on large datasets practical.

Supervised Learning deck

3. The learning setup: E, T, and P

Tom Mitchell describes learning through experience E, a task T, and a performance measure P: performance on the task improves with experience. For digit recognition, E is labeled images, T is predicting a digit, and P might be accuracy on unseen images.

\(\mathcal{D}_{\mathrm{train}}=\{(\mathbf{x}_n,y_n)\}_{n=1}^{N}\)
\(\hat{y}=f(\mathbf{x},\boldsymbol{\theta})\)
\(\boldsymbol{\theta}_0\xrightarrow{\mathrm{training}}\boldsymbol{\theta}^{*}\)
\(\mathrm{gap}=\mathrm{accuracy}_{\mathrm{train}}-\mathrm{accuracy}_{\mathrm{test}}\)

Notation: \(\mathbf{x}\) is the input, \(y\) the correct target, \(\hat y\) the model prediction, and \(\boldsymbol{\theta}\) its trainable parameters. Training data helps choose \(\boldsymbol{\theta}\); held-out test data checks the resulting model on unseen examples.

Each pair \((\mathbf{x}_n,y_n)\) is one example. The usual independent and identically distributed (IID) assumption says examples are sampled independently from the same underlying source. If training contains repeated frames from one video while testing contains nearby frames from that video, the examples are not truly independent. If the real-world inputs differ sharply from the training source, they are not identically distributed. Either issue makes the test result less reliable as a forecast of real use.

Generalization: A high training score only shows that the model fits examples it saw. The gap between training and test accuracy shows how performance changes on unseen examples.
Follow one example. An image of a handwritten 7 has target \(y=7\).

1. The input \(\mathbf{x}\) is the image; the target \(y\) is 7.

4. The same template, different tasks

The supervised-learning pipeline remains the same, but x, y, the model output, and the metric depend on the task.

Classification chooses categories. In digit recognition there are ten possible classes, but each image has one correct class; its target can be an integer such as \(7\) or a one-hot vector with a \(1\) at position 7 and \(0\) elsewhere. Binary classification has two categories. Regression predicts a continuous value. In sequence-to-sequence learning, the answer has multiple ordered elements, so the model must produce a sequence rather than one number.

TaskWhat y looks likeExample
Multiclass classificationOne of K classes / one-hot vectorDigit image → 0 to 9
Binary classification0 or 1Sentence → negative or positive
Sequence-to-sequenceTarget sequenceText → phonemes
RegressionContinuous numberInput → curve value

5. Match the metric to the task

A performance metric measures how well predictions meet the task goal on held-out data. Different outputs need different measures: a correct class, a transcript close to the reference, or a detected box overlapping the true object. Choose the metric before interpreting whether a model is “good.”

MetricFormulaInterpretation
Accuracycorrect / totalClassification; higher is better.
WER(S + I + D) / NSpeech recognition; lower is better. N is number of ground-truth words.
IoUintersection / unionObject detection; higher means boxes overlap more.
PrecisionTP / (TP + FP)“When I predict positive, how often am I right?”
RecallTP / (TP + FN)“Of real positives, how many did I find?”
Example: TP=18, FP=6, FN=2. Precision = 18/(18+6)=0.75. Recall = 18/(18+2)=0.90. So 75% of positive predictions were correct, while 90% of actual positives were found.

Here TP means a real positive predicted positive, FP means a negative wrongly flagged positive, and FN means a positive the model missed. For speech, a substitution changes a word, an insertion adds one, and a deletion omits one. WER divides those three error counts by the number of reference words. For boxes, IoU is \(0\) when there is no overlap and \(1\) when they match exactly.

Human-rated generation

The slides use mean opinion score (MOS) for voice or video quality: people rate perceived quality, then the ratings are averaged. It captures perception that a simple exact-match score cannot.

Generated-image distribution

Fréchet Inception Distance (FID) compares features extracted from real and generated images as distributions. Lower indicates closer feature statistics; it does not tell you whether each generated image matches a particular prompt.

Assistant answers

For question answering, accuracy can check answers with a known correct response. Open-ended replies may need human or model judgments of relevance, correctness, and detail, as shown in the assistant-evaluation slide.

6. Training means minimizing loss

A metric judges the final task behavior. A loss function provides the numerical signal used while fitting parameters. For each training example, compare y to y-hat. The optimizer adjusts theta to reduce average loss across the training set.

Empirical risk minimization (ERM) is the name for minimizing the mean loss over the training examples you actually have. “Empirical” means measured from observed data; “risk” means expected error. A low empirical risk is the training goal, while a separate test metric checks how that choice fares on new examples.

\(R_{\mathrm{emp}}(f,\mathbf{X},\mathbf{y})=\frac{1}{N}\sum_{n=1}^{N}\ell(y_n,f(\mathbf{x}_n,\boldsymbol{\theta}))\)

\(\mathrm{MSE}=\frac{1}{N}\sum_n(y_n-\hat{y}_n)^2\)
\(\mathrm{CE}=-\sum_i y_i\log(p_i)\)
\(\mathrm{BCE}=-[y\log p+(1-y)\log(1-p)]\)

Cross-entropy intuition: when y is one-hot, categorical cross-entropy becomes negative log of the probability placed on the correct class. A correct class probability of 0.75 gives −log(0.75) ≈ 0.288. A confident wrong prediction gives a much larger loss.

7. Prediction is not causation

Seeing umbrellas is associated with rain, but giving someone an umbrella does not make it rain. Prediction studies what is observed, \(p(y\mid x)\). Causal reasoning asks what changes when we intervene, \(p(y\mid\operatorname{do}(x))\). A counterfactual asks what would have happened in this particular situation under a different action. The slides connect this distinction to open questions about broader AI capabilities.

8. Check your understanding

Explain supervised learning using E, T, and P.

Define E as labeled experience/data, T as learning a mapping f(x, theta), and P as a test metric. Then explain that training adjusts theta from the training set, while P is measured on unseen test data. Finish with one concrete example such as digit classification.

Why is a test set necessary when training loss is low?

Low training loss only says the model fits the observed examples. The test set estimates generalization to unseen examples. Compare training and test performance using the generalization gap; a large gap can indicate overfitting.

Compare precision and recall with a use case.

Precision is TP/(TP+FP): it limits false alarms among predicted positives. Recall is TP/(TP+FN): it limits missed actual positives. In disease screening, missing true cases can be costly, so recall is often important; the appropriate trade-off depends on error cost.

Compute categorical cross-entropy for y=[0,1,0] and p=[0.10,0.75,0.15].

CE = −[0 log(.10) + 1 log(.75) + 0 log(.15)] = −log(.75) ≈ 0.288. Explain that the correct class had probability .75, so the loss is relatively low.
